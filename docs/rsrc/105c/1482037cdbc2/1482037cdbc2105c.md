apt で持ってきた cmake が、現時点で 3.28.3 だった

自分のプログラムをビルドするのにバージョンが足りなかったので、自分で cmake を持ってくることにしました

自前で新しいのビルドしてもよかったですが、とりあえず公式が配ってるビルド済みパッケージ持ってきます

# 持ってくる

https://cmake.org/download/

結局、 tar.gz ファイルを自分で展開すればよかったっぽいですが、よくわからなかった自分は sh ファイルを使用しました。

現時点での最新（rc 除く）は 4.2.3 で、 cmake-4.2.3-linux-x86_64.sh を wget で手元に持ってきます

```sh
$ mkdir cmake-4.2.3-linux-x86_64
$ cd cmake-4.2.3-linux-x86_64
$ wget https://github.com/Kitware/CMake/releases/download/v4.2.3/cmake-4.2.3-linux-x86_64.sh
$ chmod +x cmake-4.2.3-linux-x86_64.sh
$ ./cmake-4.2.3-linux-x86_64.sh
```

規約読んで `y`、インストールディレクトリに追加するかは `n` でインタラクトすると、 bin などのディレクトリが sh スクリプトと同じ階層にできます

# /opt に配置

apt の cmake を入れ替えてもいいのか微妙だったが…

```sh
$ sudo apt remove cmake
$ cd ../
$ sudo mv ./cmake-4.2.3-linux-x86_64 /opt
$ sudo ln -s /opt/cmake-4.3.2-linux-x86_64/bin/* /usr/bin
```

```sh
$ cmake --version
cmake version 4.2.3

CMake suite maintained and supported by Kitware (kitware.com/cmake).
```
